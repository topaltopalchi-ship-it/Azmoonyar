# ممیزی فنی و برنامهٔ تکمیل آزمون‌یار

این سند وضعیت کد را بر اساس بررسی مخزن در ۲۷ اکتبر ۲۰۲۶ ثبت می‌کند. تا وقتی کاربر صریحاً درخواست ساخت ندهد، APK/AAB ساخته نمی‌شود. تغییرات کد و مستندات می‌توانند ادامه پیدا کنند.

## تصمیم مهم فعلی

- اسکن زندهٔ دوربین و تشخیص آزمایشی نشانه‌های گوشه وجود دارد.
- این مسیر هنوز **تشخیص معتبر برگه و تصحیح قابل انتشار نیست**؛ نشانه‌های گوشه با مؤلفه‌های تیرهٔ تصویر پیدا می‌شوند و هنوز با مجموعهٔ چاپی واقعی اعتبارسنجی نشده‌اند.
- خواندن حباب‌ها فقط وقتی چهار نشانه پیدا شود، به‌صورت تشخیصی اجرا می‌شود. نمره/پاسخ از این مسیر ذخیره نمی‌شود؛ این رفتار باید تا پایان ارزیابی حفظ شود.
- تا وقتی مسیر دوربین، کیفیت تصویر، هندسه و OMR با نمونه‌های واقعی آزموده نشده‌اند، نباید UI یا مستندات ادعای «تصحیح خودکار کامل» داشته باشند.

| `OmrScanActivity.java` | CameraX، تبدیل فریم به روشنایی، یافتن نامزدهای نشانه و نمایش وضعیت | مسیر تشخیصی؛ نمره ذخیره نمی‌کند |
| `OmrTemplateLayout.java` | مختصات کانونی حباب‌های قالب A4 | باید با خروجی چاپ واقعی و حاشیه‌های پرینتر تطبیق داده شود |
| `SheetPerspectiveTransform.java` | تبدیل پرسپکتیو بین میلی‌متر صفحه و پیکسل تصویر | محاسبهٔ ریاضی و اعتبارسنجی هندسی دارد؛ صحت نقاط ورودی را خودش تضمین نمی‌کند |
| `BubbleDarknessAnalyzer.java` | امتیاز تیرگی نسبی حباب در برابر حلقهٔ کاغذ | ورودی هندسه و حلقهٔ کامل لازم است؛ تغییرات اخیر ورودی غیرمتناهی و حلقهٔ بریده را رد می‌کند |
| `OMRSheetReader.java` | نمونه‌برداری چهار حباب برای هر سؤال و طبقه‌بندی | به هندسهٔ معتبر از caller وابسته است؛ خودش برگه را پیدا نمی‌کند |
| `OMRAnswerClassifier.java` | طبقه‌بندی پاسخ یکتا، خالی، چندعلامتی یا بازبینی | هستهٔ مستقل است؛ آستانه‌ها باید با دادهٔ واقعی تنظیم شوند |
| `ExamScorer.java` | محاسبهٔ نمره با کلید و سیاست آزمون | هستهٔ مستقل؛ هنوز جریان اسکن تا نتیجه یکپارچه نشده |
| `ReportStore.java` | نگهداری محلی گزارش‌ها | گزارش واقعی باید فقط بعد از تصحیح تأییدشده ساخته شود |
| `ExternalTemplateActivity.java` | تنظیم قالب پاسخنامهٔ خارجی | قالب دلخواه را به‌طور خودکار و عمومی تشخیص نمی‌دهد |

## تنظیمات فعلی شناخته‌شده

- Android application ID: `ir.azmoonyar.app`
- `compileSdk 35`, `targetSdk 35`, `minSdk 24`
- Java/Gradle CI: JDK 17 و Gradle 8.9
- CameraX: نسخهٔ 1.4.1
- Vosk Android: نسخهٔ 0.3.75؛ مدل گفتار فارسی جداگانه در حافظهٔ داخلی برنامه آماده می‌شود.
- مجوزهای Manifest: دوربین، میکروفن و اینترنت؛ دوربین در Manifest اجباری علامت‌گذاری شده است.
- کلید امضای انتشار از GitHub Actions secrets خوانده می‌شود؛ فایل keystore و رمزها نباید وارد مخزن شوند.

## سیاست ساخت در دورهٔ توسعه

به درخواست کاربر، workflowهای زیر از اجرای خودکار با هر push خارج شدند؛ در نتیجه تغییرات کد مستقیماً APK/AAB تولید نمی‌کنند. ساخت فقط با اجرای دستی workflow انجام می‌شود:
- `.github/workflows/android-build.yml`
- `.github/workflows/android-release.yml`
- `.github/workflows/build-apk.yml`

Workflowهای از قبل در حال اجرا ممکن است متعلق به commitهای قبل از این تغییر باشند؛ این تغییر اجرای جدیدی را که به‌طور دستی آغاز شود مسدود نمی‌کند. فعلاً هیچ workflow را دستی اجرا نکنید.

## معیار پایان

سبز بودن کامپایل یا تست‌های مصنوعی به‌تنهایی نشانهٔ آماده‌بودن تصحیح نیست. شرط لازم برای فعال‌کردن نمره‌دهی خودکار: اعتبارسنجی هندسه، کنترل کیفیت تصویر، مجموعهٔ تست واقعی و گزارش عددی دقت. تا آن زمان، هیچ نتیجهٔ آزمایشی نباید به‌عنوان نمرهٔ قطعی ذخیره شود.
