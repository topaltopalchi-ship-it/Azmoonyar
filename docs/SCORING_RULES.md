# قواعد نمره‌دهی هسته‌ای

ExamScorer یک هستهٔ جاوای مستقل برای نمره‌دهی پاسخ‌های طبقه‌بندی‌شده است؛ هنوز به رابط برنامه، QR یا تصویر دوربین وصل نشده است.

- کلید باید برای هر سؤال یک گزینهٔ A تا D داشته باشد و طول آن با پاسخ‌ها برابر باشد.
- پاسخ صحیح نمرهٔ صحیح، پاسخ اشتباه و چندعلامتی جریمهٔ پاسخ غلط، و پاسخ خالی نمرهٔ خالی می‌گیرد.
- پاسخ با وضعیت «نیازمند بازبینی» عمداً نمره نمی‌گیرد و نتیجه ناقص می‌ماند؛ درصد نهایی تا تعیین تکلیف پاسخ‌ها ارائه نمی‌شود.
- جریمهٔ پاسخ غلط یا امتیاز پاسخ خالی فقط در صورت تعیین صریح سیاست آزمون اعمال می‌شود.
- آزمون‌های واحد قوانین پایه و ورودی‌های نامعتبر را پوشش می‌دهند. این تست‌ها جای آزمون با تصویر واقعی یا اتصال کامل جریان تصحیح را نمی‌گیرند.
