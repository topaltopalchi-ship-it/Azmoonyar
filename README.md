# آزمون‌یار | AzmoonYar

**Offline-first Android answer-sheet scanner and multiple-choice exam grader.** A Windows desktop edition is planned for a later milestone.

آزمون‌یار برای اسکن پاسخنامه‌های چهارگزینه‌ای، تصحیح بر اساس کلید آزمون و تهیه نتایج طراحی می‌شود. هدف، اجرای محلی و آفلاین است؛ پاسخ‌های مبهم باید برای بازبینی علامت‌گذاری شوند، نه اینکه برنامه حدس بزند.

## اصول محصول
- **آفلاین‌محور:** اسکن، تشخیص پاسخ، نمره‌دهی و ذخیره محلی بدون اینترنت.
- **OMR:** تشخیص حباب‌های پرشده در پاسخنامه استاندارد؛ نه تکیه بر تیک و ضربدرهای آزاد.
- **بازبینی به‌جای حدس:** پاسخ سفید، چندعلامتی، کم‌اطمینان یا برگه کج/نامعتبر برای بررسی انسانی مشخص می‌شود.
- **قابلیت پیگیری:** تصویر اصلی اسکن و اصلاحات اپراتور حفظ می‌شوند.
- **حریم خصوصی:** اطلاعات دانش‌آموزان و نتایج روی دستگاه می‌مانند مگر کاربر خودش خروجی بگیرد.
- **مقیاس:** طراحی و آزمایش برای آزمون‌های حدود ۱۰۰ تا ۱۰۰۰ پاسخنامه.

## قابلیت‌های برنامه‌ریزی‌شده
1. تعریف آزمون، کلید پاسخ و قواعد نمره‌دهی.
2. اسکن پاسخنامه چاپی با دوربین اندروید.
3. خواندن شناسه برگه/آزمون از QR در صورت وجود.
4. تشخیص حباب‌ها و علامت‌گذاری پاسخ‌های نامطمئن.
5. بازبینی و اصلاح پاسخ‌های علامت‌گذاری‌شده.
6. محاسبه نمره و گزارش نتایج.
7. خروجی گرفتن از نتایج در مراحل بعدی.
8. توسعه نسخه ویندوز پس از تثبیت مدل داده و مسیر تشخیص.

## دقت و مسئولیت‌پذیری
هیچ سیستم OMR نمی‌تواند در همه شرایط نور، چاپ، کاغذ و دوربین صادقانه خطای صفر را تضمین کند. باید کیفیت تصویر بررسی شود، آستانه اطمینان وجود داشته باشد و موارد مبهم برای بازبینی انسانی بمانند. ادعاهای دقت باید با داده‌های واقعی و برچسب‌گذاری‌شده سنجیده شوند.

## وضعیت پروژه
این مخزن در مرحله تعریف دامنه و برنامه فنی است. پیاده‌سازی اندروید، آزمون‌های خودکار، نمونه پاسخنامه و نسخه انتشار تا زمانی که واقعاً ساخته و بررسی نشده‌اند، کامل محسوب نمی‌شوند.
