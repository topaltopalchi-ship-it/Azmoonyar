# آزمون‌یار | AzmoonYar

**Offline-first Android answer-sheet scanner and multiple-choice exam grader.** A Windows desktop edition is planned for a later milestone.

آزمون‌یار برای اسکن زنده پاسخنامه‌های چهارگزینه‌ای، تصحیح بر اساس کلید آزمون و تهیه نتایج طراحی می‌شود. کاربر نباید مجبور باشد هر برگه را با دکمه شاتر عکس بگیرد: دوربین به‌صورت پیوسته فعال می‌ماند و پردازش فریم‌ها در حافظه انجام می‌شود.

## اصول محصول
- **اسکن زنده بدون شاتر:** کاربر فقط برگه را جلوی دوربین می‌گیرد؛ نیازی به گرفتن عکس دستی نیست.
- **آفلاین‌محور:** تشخیص و ذخیره محلی بدون نیاز به اینترنت هنگام اسکن.
- **OMR:** تشخیص حباب‌های پرشده در پاسخنامه استاندارد؛ نه تکیه بر تیک و ضربدرهای آزاد.
- **بازبینی به‌جای حدس:** پاسخ سفید، چندعلامتی، کم‌اطمینان یا برگه نامعتبر باید برای بررسی انسانی مشخص شود.
- **حریم خصوصی:** فریم‌های دوربین در حافظه پردازش می‌شوند؛ تصویر دائمی پاسخنامه در این پیاده‌سازی ذخیره نمی‌شود.
- **مقیاس:** طراحی و آزمایش برای آزمون‌های حدود ۱۰۰ تا ۱۰۰۰ پاسخنامه.

## وضعیت پیاده‌سازی فعلی
- [x] تعریف آزمون و تعداد سؤال در حافظه محلی.
- [x] ثبت و نمایش کلید پاسخ.
- [x] پیش‌نمایش زنده دوربین با CameraX.
- [x] چاپ پاسخنامه استاندارد چهارگزینه‌ای از داخل برنامه؛ هر صفحه A4 حداکثر ۱۰۰ سؤال و شماره‌گذاری پیوسته در صفحه‌های بعدی.
- [ ] تشخیص خودکار محدوده و گوشه‌های کاغذ، بررسی وضوح/نور/زاویه.
- [ ] خواندن حباب‌ها (OMR)، تشخیص پاسخ سفید/چندعلامتی/مبهم و نمره‌دهی.
- [ ] نتایج آزمون، صف بازبینی و خروجی گزارش.
- [ ] آزمون چاپ چندبرگی روی گوشی/پرینتر واقعی و ساخت APK انتشار امضاشده.



## دقت و مسئولیت‌پذیری
هیچ سیستم OMR نمی‌تواند در همه شرایط نور، چاپ، کاغذ و دوربین خطای صفر را تضمین کند. باید کیفیت تصویر بررسی شود، آستانه اطمینان وجود داشته باشد و موارد مبهم برای بازبینی انسانی بمانند. ادعاهای دقت باید با داده‌های واقعی و برچسب‌گذاری‌شده سنجیده شوند.
