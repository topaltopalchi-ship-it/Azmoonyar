# آزمون‌یار | AzmoonYar

**Offline-first Android answer-sheet scanner and multiple-choice exam grader.** A Windows desktop edition is planned for a later milestone.

آزمون‌یار برای ساخت آزمون، تولید مدل‌های A و B و مدل‌های بیشتر، چاپ پرسشنامه و پاسخنامهٔ هماهنگ، اسکن پاسخنامه و تصحیح بر اساس کلید همان مدل طراحی شده است. QR می‌تواند برای شناسایی شرکت‌کننده و مدل آزمون روی برگه چاپ شود؛ در تعریف آزمون امکان انتخاب روش QR یا ورود دستی نام نیز وجود دارد. قالب خام بدون QR هم برای پاسخ‌نویسی دستی قابل چاپ است، اما به کلید اختصاصی مدل وصل نمی‌شود.

## اصول محصول
- **اسکن زنده بدون شاتر:** کاربر برگه را جلوی دوربین می‌گیرد؛ نیازی به گرفتن عکس دستی نیست.
- **آفلاین‌محور:** پردازش و ذخیرهٔ نتایج به‌صورت محلی.
- **OMR:** خواندن حباب‌های پاسخ، نه تیک و ضربدر آزاد.
- **بازبینی به‌جای حدس:** پاسخ‌های مبهم نباید به‌عنوان نمرهٔ قطعی ذخیره شوند.
- **حریم خصوصی:** فریم‌های دوربین در حافظه پردازش می‌شوند؛ تصویر دائمی پاسخنامه در مسیر اسکن زنده ذخیره نمی‌شود.

## وضعیت پیاده‌سازی فعلی

- [x] تعریف آزمون، تعداد سؤال و کلید پاسخ در حافظهٔ محلی.
- [x] رابط فارسی و راست‌به‌چپ، همراه با دکمهٔ اصلی بزرگ، صورتی، بیضی و برجسته برای «اسکن و تصحیح».
- [x] پیش‌نمایش زندهٔ دوربین با CameraX و پردازش فریم‌ها بدون شاتر.
- [x] چاپ پاسخنامهٔ چهارگزینه‌ای A4 با چهار مربع سیاه پُر در گوشه‌ها.
- [x] شناسایی آزمایشی مربع‌های گوشه در اسکنر؛ پشتیبانی کدی از نشانه‌های قدیمی کوچک‌تر نیز وجود دارد.
- [x] ثبت شرکت‌کنندگان و تولید برگهٔ QR اختصاصی هر نفر؛ امکان انتخاب شناسایی با QR یا ورود دستی نام.
- [x] ساخت مدل‌های تصادفی A، B و مدل‌های بیشتر از بانک سؤال، با ترتیب سؤال/گزینه و کلید پاسخ جداگانه برای هر مدل.
- [x] چاپ هماهنگ پرسشنامه و پاسخنامهٔ مدل‌دار؛ QR پاسخنامه شناسهٔ مدل را برای اتصال به کلید همان مدل نگه می‌دارد.
- [x] تنظیم الگوی پاسخ‌ها برای ورود سریع پاسخ‌های تکرارشونده.
- [x] قالب پاسخنامهٔ خارجی: تنظیم دستی تعداد سؤال/گزینه، ثبت کلید، انتخاب عکس نمونه، کالیبراسیون محدودهٔ جدول و شبکهٔ حباب‌ها، سپس خواندن عکس برگهٔ پُرشده.
- [x] ذخیرهٔ نتیجهٔ پاسخنامهٔ خارجی در نتایج محلی فقط وقتی طبقه‌بندی پاسخ‌ها مورد مبهمی برای بازبینی گزارش نکند.
- [ ] تشخیص عمومی و خودکار چیدمان هر نوع پاسخنامهٔ خارجی، بدون تنظیم دستی قالب.
- [ ] اتصال کامل قالب‌های خارجی به اسکن زندهٔ دوربین.
- [ ] کنترل اعتبارسنجی‌شدهٔ وضوح، نور، حرکت، چرخش و هندسه قبل از نمره‌دهی.
- [ ] صف بازبینی تعاملی برای اصلاح پاسخ‌های مبهم و ثبت سابقهٔ اصلاح.
- [ ] اعتبارسنجی با مجموعه‌ای از پاسخنامه‌های واقعی چاپ‌شده روی گوشی‌ها و چاپگرهای متفاوت.
- [ ] تأیید نهایی خروجی انتشار امضاشده برای آخرین تغییرات.

## محدودیت مهم

وجود کد تشخیص گوشه یا نمونه‌برداری از حباب به‌تنهایی به معنی اعتبارسنجی دقت OMR نیست. اسکنر قالب داخلی هنوز باید با پاسخنامه‌های واقعی و شرایط متفاوت نور، زاویه، چاپ و دوربین آزموده شود. قالب خارجی فعلاً به تنظیم دستی محدوده و شبکهٔ حباب‌ها نیاز دارد؛ تشخیص خودکار هر چیدمان دلخواه تضمین نشده است. نتیجهٔ دارای پاسخ مبهم به‌عنوان نمرهٔ قطعی ذخیره نمی‌شود.
